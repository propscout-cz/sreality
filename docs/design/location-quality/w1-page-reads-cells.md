## What the page renders (no threshold held in the browser)
- Header: `measuredLine(row)`.
- Matrix: rows = portals from `cell.portal`, columns = each cell's arm by Health's `tail` (exported from `lib/healthChecks.ts`, PortalMatrix's own helper), in the gauge's order; no per-key table in TS. No `'town'` fallback: every stored shape since wave 6 names `{portal}/town`. Each cell is Health's `MatrixCell` (exported from `PortalMatrix.tsx`; it omits the arm when the column already names it) over `verdictOf(row, [cell])` (exported from `lib/healthChecks.ts`; `portalVerdict` now calls it): an OK cell is a quiet dot with its message as the title, any other says its word and value, and a row the view reads Not measured shows Not measured everywhere. The responsive table classes are PortalMatrix's. A row click (or its portal button) sets the inspector's source.
- Fleet strip: cells with `portal === null` (`served/*`, `registry`, `freshness/*`), each through `verdictOf`.
- Selected portal: two `BarList`s from `{p}/street` `facts.grains` and `{p}/outside` `facts.disputed`, in the matrix's figures (`fmtNumber`), withheld while the row is stale.
- Below: `<CheckRow row={{ ...row, owner_path: '' }} />` (no self-link), then the inspector and corrections (unchanged).
