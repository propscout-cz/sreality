# Agents may assess condition from photos through a structured, cached assessment; rule 14 reopens for that alone

Rule 14 parked the two-axis 1–5 condition scoring on 2026-10-20: nothing reads the levels. The investment analyst needs
condition from photos (view, neighbourhood as seen, shared spaces, and for renovated flats kitchen, bathrooms,
equipment, finish quality, lighting, styling). We chose a new structured photo assessment: one judgement and a score
per facet with a one-line evidence note, computed from the ad's photos and floor plan, cached per photo set and prompt
version so a property is judged once, callable by agents on at most 10 properties per run. The parked 1–5 scorer stays
parked, cohort statistics keep using the condition the portal states, and Browse shows no facet until a further ruling.
The facet list and wording live in a versioned reference file the operator edits. Operator ruling Q17, Q30, Q33 of
2026-10-25.
