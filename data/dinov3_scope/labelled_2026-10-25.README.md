# DINOv3 targeted scope: labelled ads + town neighbours (2026-10-25)

`labelled_2026-10-25.txt.gz` holds the listing ids for `dinov3_embed_backfill.yml` with `scope=ids`.
It has one id per line, sorted ascending and de-duplicated, gzip with no name and mtime 0. It holds
**ad ids only**: no broker, contact or text field. Research input for
`autodedup-artifacts/research/experiments/dinov3_plan.md` §3.1 (tiers A and B).

- asof: **2026-10-25 12:04:51Z**. Verdicts and must_not_link rows are cut at this instant, and
  neighbour candidates at `listings.id <= 19444033` (the max id then). `listings.property_id` and
  `listing_location` were read live during 12:05-12:25Z.
- Source: production, read-only (`execute_sql`, SELECT only). Ids were pulled in 7 chunks, each
  checked against the database's count, min, max, `sum(id)` and `sum(id*rank)`.
- sha256 of the .gz: `d6fa1a9ccbebc58532dca038e245efbd3285d7d8b93947a5fa9aa9d9ca93d471`; 8,880 lines; `sum(id)` 73,781,538,889.

## Definitions

**Operator truth** is the corrected definition from `blocks_rules_audit.md` (CURRENT). For each pair, the
latest human verdict wins (`kind='pair'`, `decided_by not like 'autodedup%'`, `unsure` dropped,
`decided_at desc, id desc`).
- SAME means the latest verdict is `same`, both ads sit in one `property_id` today, and the pair is not in
  `autodedup.must_not_link`. That gives 3,469 pairs.
- DIFFERENT means `must_not_link` union a latest verdict in (`different`, `same_building_different_unit`,
  `same_project_different_unit`). That gives 850 pairs.

**Tier A** is every ad in any SAME or DIFFERENT pair. That is 3,001 ads in 1,179 properties. The plan's 2,782
used the older prescribed truth (`operator merge%` notes).

**Tier B** follows plan Q8. A cell is (`listing_location.obec_kod`, `category_main`, `category_type`). Each
cell's candidates are its ads that are outside every tier-A property (`property_id` null or not a tier-A
property), are not in A, and have `id <= 19444033`. The candidates are ranked 0..N-1 by `hashtext(id::text), id`.
The i-th labelled ad of the cell (0-based, by id) takes ranks 2i and 2i+1 (mod N). Tier B is the union of the
picks, which is the 2k lowest-hash candidates of a cell holding k labelled ads. Neighbours are distinct across
labelled ads while the cell has room. The plan's own Q8 SQL was not saved, so this is a rebuild of its rule,
and its 5,448 / 84,778 were not reproduced.

## Caveats

- 9 tier-A ads and 86 tier-B ads have no stored image. Those ids are in the file, and the lane finds nothing for them.
- 1 tier-A ad has no `obec_kod`, so it has no cell and no neighbours. 8 tier-A ads sit in cells with no candidate.
  In 13 cells, N < 2k, so labelled ads share neighbours (105 fewer picks than 2 per ad).
- No activity filter was applied. Tier A is 1,189 active / 3,001, and tier B is 2,092 active / 5,879.
- The scope is 7 % larger than the plan's (142,338 against 132,450 images). That is about 56 min at
  42.5 img/s pod-batched, but **about 3.3 h at the 12 img/s serial rate, which is over `job_max_seconds=10800`**.

## SQL (the final select of each chunk/aggregate query followed this CTE)

```sql
with lv as (  -- latest human pair verdict per pair ('unsure' dropped)
  select distinct on (least(listing_lo,listing_hi), greatest(listing_lo,listing_hi))
         least(listing_lo,listing_hi) lo, greatest(listing_lo,listing_hi) hi, verdict
  from autodedup.verdicts
  where kind='pair' and decided_by not like 'autodedup%' and verdict<>'unsure'
    and decided_at <= '2026-10-25 12:04:51+00'
  order by least(listing_lo,listing_hi), greatest(listing_lo,listing_hi), decided_at desc, id desc),
pos as (  -- SAME: latest verdict same, both ads in one property today, not in must_not_link
  select lv.lo, lv.hi from lv
  join public.listings a on a.id=lv.lo join public.listings b on b.id=lv.hi
  where lv.verdict='same' and a.property_id=b.property_id
    and not exists (select 1 from autodedup.must_not_link m where m.listing_lo=lv.lo and m.listing_hi=lv.hi)),
neg as (  -- DIFFERENT: must_not_link union latest verdict in the three negative values
  select lo, hi from lv where verdict in ('different','same_building_different_unit','same_project_different_unit')
  union select least(listing_lo,listing_hi), greatest(listing_lo,listing_hi)
  from autodedup.must_not_link where created_at <= '2026-10-25 12:04:51+00'),
a as (select lo as id from pos union select hi from pos union select lo from neg union select hi from neg),
lp as (select distinct l.property_id from a join public.listings l on l.id=a.id where l.property_id is not null),
cells as materialized (  -- the (town, category_main, category_type) cells of the labelled ads; k = labelled ads in the cell
  select ll.obec_kod ok, l.category_main cm, l.category_type ct, count(*) k
  from a join public.listings l on l.id=a.id join public.listing_location ll on ll.listing_id=a.id
  where ll.obec_kod is not null and l.category_main is not null and l.category_type is not null
  group by 1,2,3),
town_ads as materialized (  -- every ad located in a town that holds a labelled ad
  select nl.listing_id id, nl.obec_kod ok from public.listing_location nl
  where nl.obec_kod in (select ok from cells)),
cand as (  -- same-cell ads outside every labelled property (and outside A), ranked 0..N-1 by hashtext(id) per cell
  select n.id, c.k,
         row_number() over (partition by c.ok, c.cm, c.ct order by hashtext(n.id::text), n.id) - 1 as r,
         count(*) over (partition by c.ok, c.cm, c.ct) as nn
  from town_ads t
  join public.listings n on n.id=t.id
  join cells c on c.ok=t.ok and c.cm=n.category_main and c.ct=n.category_type
  where n.id <= 19444033
    and n.id not in (select id from a)
    and (n.property_id is null or n.property_id not in (select property_id from lp))),
b as (select id from cand where r < 2*k),  -- labelled ad i (0-based, by id, in its cell) takes ranks 2i and 2i+1 mod N
scope as (select id, 'A'::text as tier from a union all select id, 'B' from b)
-- ids: select id from scope order by id
-- chunks: r as (select id, row_number() over (order by id) rn, id - lag(id,1,0::bigint) over (order by id) dl from scope)
--         select count(*), min(id), max(id), sum(id), sum(id::numeric*rn), string_agg(<first id, then deltas>, ' ' order by rn)
--         from r where rn between <lo> and <hi>
-- images: scope join public.images i on i.listing_id = scope.id where i.storage_path is not null,
--         exists(image_dinov3_embeddings e where e.image_id = i.id [and the seven config identity columns])
```
